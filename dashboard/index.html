Where a Human Was Needed

1. Auth method disambiguation
Pipeline auto-detected OAuth2 vs API_Key from docs, but 3 apps (ServiceNow, PitchBook, Bright Data) used hybrid/multi-auth that required a human to read enterprise admin guides and identify the fallback auth. Human corrected auth_methods for these.
2. Gating classification edge cases
Zendesk Sunshine API flagged as "gated" because its main page requires sales contact. A human spotted the separate self-serve dev portal and reclassified it. DocuSign had the same issue — eSignature API is self-serve but buried under enterprise docs.
3. API breadth over/under-estimation
PitchBook listed 20+ endpoints in docs but half required separate licensing tiers. Kayako had endpoints documented that returned 404. Human verified by actually testing 3-5 random endpoints per low-confidence app and corrected breadth from Medium → Narrow.
4. MCP/hallucination check
Pipeline found "MCP support" for Devin and Otter AI. Human verified both by visiting the actual MCP server repos — confirmed real. However, 2 apps (Grain, Consensus) mentioned "AI" but had no actual MCP server; human corrected those flags to false.
