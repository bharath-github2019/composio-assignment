Agent Methodology

Architecture: Composio MCP + structured extraction pipeline with Pydantic validation. 10 batch-processed categories of 10 apps each.

Extraction: Each app evaluated on auth methods, self-serve accessibility, API surface (type, breadth, MCP readiness), and buildability verdict. Confidence scored per field using rubric: 1.0=explicit docs, 0.8-0.9=inferred, 0.6-0.7=ambiguous, <0.6=conflicting.

Human-in-the-loop: Apps with confidence <0.7 flagged for review. 1 app (PitchBook) flagged. 25-app stratified verification sample with blind review protocol.
